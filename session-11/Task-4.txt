TASK 4: Flipkart Products Matrix & Product Revenue Function
================================================================================

1. Problem Description:
--------------------------------------------------------------------------------
Imagine you have a table of 5 Flipkart products with columns for price and 
quantity sold. Represent this data as a matrix in Python, then write a function 
to calculate the total revenue for each product.

Hint: Multiply price and quantity for each row, then print the results.

--------------------------------------------------------------------------------
2. Mathematical Formulation:
--------------------------------------------------------------------------------
Let P be a 5x2 Matrix where:
- Column 0 represents Unit Price in Rupees (Rs.)
- Column 1 represents Quantity Sold (Units)
- Each row i represents a distinct Flipkart product:

                     Col 0: Price (Rs)     Col 1: Quantity Sold
Row 0: Earbuds              1,499                   50
Row 1: Phone Case             299                  120
Row 2: Power Bank             999                   40
Row 3: Fast Charger           499                   85
Row 4: BT Speaker           1,999                   30

Revenue Calculation:
For each product row i:
      Revenue_i = Price_i * Quantity_i = P[i][0] * P[i][1]

Total Store Revenue:
           4
      R = Sum Revenue_i
          i=0

--------------------------------------------------------------------------------
3. Python Implementation (task4_flipkart_revenue_matrix.py):
--------------------------------------------------------------------------------
```python
import numpy as np

# 1. Represent 5 Flipkart products as a 5x2 matrix
flipkart_matrix = [
    [1499, 50],   # Product 1: Wireless Earbuds
    [299, 120],   # Product 2: Smartphone Case
    [999, 40],    # Product 3: Power Bank
    [499, 85],    # Product 4: Fast Charger
    [1999, 30]    # Product 5: Bluetooth Speaker
]

# 2. Function to calculate revenue for each product
def calculate_product_revenues(matrix):
    """
    Multiplies price and quantity for each row in the product matrix.
    """
    revenues = []
    for row in matrix:
        price = row[0]
        qty   = row[1]
        rev   = price * qty
        revenues.append(rev)
    return revenues

# 3. Calculate and display revenues
product_names = [
    "Wireless Earbuds", "Smartphone Case", "Power Bank", 
    "Fast Charger", "Bluetooth Speaker"
]

revenues = calculate_product_revenues(flipkart_matrix)

for name, row, rev in zip(product_names, flipkart_matrix, revenues):
    print(f"{name:20}: Rs. {row[0]} x {row[1]:3} units = Rs. {rev:,}")

print(f"\nTotal Store Revenue : Rs. {sum(revenues):,}")
```
