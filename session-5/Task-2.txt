TASK 2: Python Random Sampling Simulation
==========================================

Problem Statement:
Given a list of 1000 fake user IDs (user1 to user1000), select 50 random users to simulate a survey sample using Python's `random.sample()` function.

------------------------------------------
Python Script: `random_sampling.py`
------------------------------------------
```python
import random

# Generate population of 1000 fake user IDs
population = [f"user{i}" for i in range(1, 1001)]

# Select 50 random users without replacement
sample = random.sample(population, 50)

# Print selected user IDs
print("Selected 50 Random Users:")
print(sample)
```

Key Characteristics of random.sample():
1. Sampling Without Replacement: No single user can be picked more than once in the same sample.
2. Equal Probability: Every user in the 1,000-user population has an equal chance (50 / 1000 = 5%) of being selected.
