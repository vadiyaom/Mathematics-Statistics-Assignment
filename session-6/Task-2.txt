TASK 2: Two-Sample t-Test on Zomato A/B Test Order Values
=============================================================

1. Given Problem Data:
-------------------------------------------------------------
- Group A (New Home Page):
    Sample Mean (x_bar_A)       = Rs. 350
    Sample Std Dev (s_A)        = Rs. 50
    Sample Size (n_A)           = 30 users

- Group B (Old Home Page):
    Sample Mean (x_bar_B)       = Rs. 320
    Sample Std Dev (s_B)        = Rs. 50
    Sample Size (n_B)           = 30 users

- Significance Level (alpha)    = 0.05

-------------------------------------------------------------
2. Hypotheses:
-------------------------------------------------------------
- Null Hypothesis (H0):
  mu_A = mu_B (The new home page does not change the average order value).
- Alternative Hypothesis (H1):
  mu_A != mu_B (Two-tailed) or mu_A > mu_B (One-tailed).

-------------------------------------------------------------
3. Mathematical Calculations:
-------------------------------------------------------------
A. Degrees of Freedom (df):
   df = n_A + n_B - 2 = 30 + 30 - 2 = 58

B. Pooled Standard Deviation (s_p):
   Since both sample standard deviations are identical (s_A = s_B = 50):
   s_p = 50.0

C. Standard Error of the Difference (SE):
   SE = s_p * sqrt( (1 / n_A) + (1 / n_B) )
      = 50 * sqrt( (1 / 30) + (1 / 30) )
      = 50 * sqrt( 2 / 30 )
      = 50 * sqrt( 1 / 15 )
      = 50 * 0.258199
      = 12.9099

D. Calculated t-statistic:
   t = (x_bar_A - x_bar_B) / SE
     = (350 - 320) / 12.9099
     = 30 / 12.9099
     = 2.3238

-------------------------------------------------------------
4. p-Value (Calculated using scipy.stats.ttest_ind_from_stats):
-------------------------------------------------------------
- Two-Tailed p-value = 0.02366 (or approximately 0.0237)
- One-Tailed p-value = 0.01183 (or approximately 0.0118)

-------------------------------------------------------------
5. Decision at alpha = 0.05:
-------------------------------------------------------------
- Comparison:
  p-value (0.0237) < alpha (0.05)

- Statistical Decision:
  **REJECT THE NULL HYPOTHESIS (H0)**.

- Business Conclusion:
  There is statistically significant evidence at the 5% significance level to conclude that the new Zomato home page design produces a higher average order value (Rs. 350) compared to the old design (Rs. 320). The observed Rs. 30 increase is unlikely to be the result of random chance.
