TASK 1: Generate 100 Normally Distributed Numbers & Plot Bell Curve
================================================================================

1. Problem Description:
--------------------------------------------------------------------------------
Generate 100 random numbers in Python that follow a normal distribution with 
mean 50 and standard deviation 10 using numpy, then plot the bell curve using 
matplotlib.

--------------------------------------------------------------------------------
2. Theoretical Background (Normal / Gaussian Distribution):
--------------------------------------------------------------------------------
A continuous random variable X follows a Normal Distribution with parameters 
Mean (mu) and Standard Deviation (sigma), denoted as X ~ N(mu, sigma^2).

Probability Density Function (PDF):
                                  1                  -1/2 * ((x - mu) / sigma)^2
              f(x) = ---------------------------- * e
                      sigma * sqrt(2 * pi)

Key Properties:
1. Symmetry: The distribution is perfectly symmetric around its mean mu = 50.
2. Unimodal Peak: A single highest peak occurs exactly at the mean, where 
   Mean = Median = Mode.
3. Asymptotic Tails: The curve extends infinitely in both directions without 
   touching the horizontal axis.
4. Total Area: The total area under the probability density curve equals exactly 1.

--------------------------------------------------------------------------------
3. Python Implementation (task1_normal_distribution.py):
--------------------------------------------------------------------------------
```python
import numpy as np
import matplotlib.pyplot as plt

# 1. Set parameters
mu = 50       # Mean
sigma = 10    # Standard Deviation
n = 100       # Sample size

# 2. Generate normally distributed random numbers
data = np.random.normal(loc=mu, scale=sigma, size=n)

# 3. Plot normalized histogram
plt.figure(figsize=(9, 6))
count, bins, ignored = plt.hist(data, bins=15, density=True, color="#3498DB", 
                                edgecolor="#1B4F72", alpha=0.6, label="Sample Histogram")

# 4. Overlay continuous theoretical Gaussian PDF
x_range = np.linspace(mu - 3.5 * sigma, mu + 3.5 * sigma, 300)
pdf = (1 / (sigma * np.sqrt(2 * np.pi))) * np.exp(-0.5 * ((x_range - mu) / sigma) ** 2)
plt.plot(x_range, pdf, color="#C0392B", linewidth=2.5, label="Theoretical Bell Curve")

# Add Mean and +/- 1 SD reference lines
plt.axvline(mu, color="#27AE60", linestyle="--", linewidth=2, label=f"Mean (mu={mu})")
plt.axvline(mu - sigma, color="#8E44AD", linestyle=":", label=f"-1 SD ({mu - sigma})")
plt.axvline(mu + sigma, color="#8E44AD", linestyle=":", label=f"+1 SD ({mu + sigma})")

plt.title("Normal Distribution Bell Curve (N = 100, mu = 50, sigma = 10)")
plt.xlabel("Value (X)")
plt.ylabel("Probability Density")
plt.grid(True, linestyle=":", alpha=0.6)
plt.legend()
plt.savefig("normal_distribution_bell_curve.png")
plt.show()
```

5. Visual Interpretation of the Bell Curve:
--------------------------------------------------------------------------------
Looking at `normal_distribution_bell_curve.png`:
1. Shape: The density histogram matches the classic symmetric, bell-shaped 
   contour predicted by Carl Friedrich Gauss.
2. Central Concentration: The greatest concentration of sample values clusters 
   tightly around the center point X = 50.
3. Spread & Inflection Points: The points of inflection on the bell curve 
   occur precisely at mu - sigma = 40 and mu + sigma = 60. Beyond these lines, 
   the slope flattens rapidly into the left and right tails.
